## 核心结构

- `内容` 与 `内核设计` 是唯一的顶层模式。
- 内核库仅在调用时作为焦点层出现。
- 源码仅在明确检查时进入全屏焦点层。
- 默认舒适密度，命令面板可切换紧凑密度。

## 原型交互

- 顶部模式切换：内容 / 内核设计
- 左侧或移动端底部命令坞：内容、内核库、画廊、搜索、命令
- 内容画布：待补录横幅、场景插图（重绘 / 手动插图）、引擎状态、状态进度轨道（点击查看进度与引擎状态卡）、单选行动、条件（IF）选项、可多选准备、选项折叠/展开、正文搜索条（上一个 / 下一个 / 计数 / 高亮定位）、模型芯片（文本 / 插图 / 思考）、灵感
- 世界菜单：世界线切换与新建、会话切换与新建、管理世界线 / 管理会话（重命名、删除确认、绑定内核）、导出进度包、新手引导、世界设置
- 内核设计：快速提示（梳理核心体验 / 检查规则漏洞 / 设计开局出身）、AI 对话、六项契约检查点、接受/修订、源码检查、版本历史、发布与版本归档
- 内核库：搜索、全部/已发布/草稿/归档筛选、选择、应用到指定世界、导入、新建模板、行菜单（源码 / 版本历史 / 另存为模板 / 重命名 / 归档 / 恢复 / 删除确认）
- 画廊：插图筛选、点击查看大图（保存 / 重生成）、重生成、全部保存、导出进度包、手动插图
- 设置：主题、颜色预设、字体大小、圆角、信息密度、阅读宽度、减弱动效、跳过开场动画、状态轨道开关、文本模型（接口地址 / 密钥 / 上下文长度 / 保留轮数 / 思考程度）、插图模型（自动插图 / 尺寸 / 风格 / 质量 / 种子锁定 / 负向词）、快捷键表、数据（导出进度包 / 打开数据文件夹 / 清空图片缓存）、关于
- 源码层：编辑、验证、审计定位、移动端源码/审计切换
- 命令面板：设计 / 内核库 / 源码 / 画廊 / 设置 / 搜索正文 / 新手引导 / 主题 / 密度
- 灵动岛：载入、保存、生成、验证、发布、应用与撤销状态
- 主题切换、舒适/紧凑密度、`prefers-reduced-motion` 与设置内减弱动效开关

## 键盘

- `Ctrl+K`：进入内核设计
- `Ctrl+Shift+L`：打开内核库
- `Ctrl+.`：打开源码
- `Ctrl+G`：打开画廊
- `Ctrl+F`：搜索正文
- `Ctrl+,`：打开设置
- `Ctrl+P`：打开命令面板
- `Ctrl+Enter`：提交当前输入
- `Esc`：关闭最上层弹层 / 焦点层

## 验证范围

- 1440x900、1063x749、390x844、280x720、2560x1440
- 键盘焦点与焦点层隔离
- 深浅主题文字对比度
- `prefers-reduced-motion: reduce`
- 横向溢出与浏览器控制台

这仍是交互与视觉原型，不代表已经达到生产发布水平。正式落地前还需要连接真实数据、补齐错误/空/加载状态，并通过 Electron 集成与回归测试。
