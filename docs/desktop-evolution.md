## 主题方向

共用尺寸、间距、焦点与命令语义；主题只改变语义配色、阅读细节和轻量表面处理。经典为中性黑白与琥珀，羊皮纸为纸白/墨色与赭红，林间为苔绿与中性灰，紫晶为低饱和紫与银灰，海渊为青蓝与清晰白，蔷薇为玫瑰与石墨，高对比为纯黑白与黄/蓝焦点。用户字体、密度与明暗偏好优先。

## 验证

本地 mock 模型验证操作闭环，隔离 Electron 档案验证持久化；不以截图或静态检查代替业务验收。Android、云账号、社区市场和实时云同步不纳入此次实现。

### 正式工具接线与验收口径

作者、体验、工作台均从正式 `main.cjs` 注册，经 `preload.cjs` 暴露，在 `classic` / `proto` / `d` 复用共享模块。测试使用 `electron.launch({ args: ['.'] })`，不用专用测试宿主替代；每轮、每方案独立 `output/playwright/product-tools/run-<id>/<scheme>/profile`，不触碰用户存档或密钥。只允许 stub 原生保存对话框选路径，不替换业务 IPC。

正式工具回归覆盖正常点击入口、作者版本/差异/沙盒/记录/精选导航、工作台发布/离线用例/具体记录行、体验诊断导出，以及重启后版本、草稿记录复跑和世界线隔离。玩家夹具使用正式会话与引擎 API 建立七回合状态；普通引擎文件逐字节比较，SQLite 按只读逻辑内容比较，重启后等启动清理完成再核验。不得将孤儿夹具被清理或正常 WAL checkpoint 误判为工具改写玩家数据。

以下边界仍然成立，即使测试程序全绿也不自动变成已完成：

- 预置用量账本只证明读取、聚合、展示、报价和导出；三套入口尚未接入真实生成的统一 RuntimeTools 采集 hooks，不能宣称实时累计计费/任务控制完成。
- 作者结构测试、工作台四个固定案例都是离线确定性验证；不调用收费模型，不代表模型叙事质量或真实模型试玩。
- 真实模型漫画生成没有运行；本轮多图证据使用离线确定性图像夹具，不代表任何服务商的实际生图质量、费用或稳定性。
- 七主题 × 明暗 × 三界面的自动检查会直接设置主题 DOM 属性；它验证变量/对比度、部分面板、Escape 和窄窗，不等于通过主题设置交互持久化、全弹层与屏幕阅读器的完整辅助技术验收。
- Windows 候选安装版/便携版已构建并对解包应用做隔离 profile 启动冒烟，但未实测安装、升级、回退或旧用户数据保护；候选文件未签名。Android 真机与双端实际文件传输不在本轮。
