# C · 蓝晒制图台（绘图桌架构）

> 世界是一张横铺的图纸。时间不再纵向流淌——它是一根带菱形刻度的尺寸线，每幕是图幅上一张节点详图卡，你的每次行动是一张变更单，落账是图签栏敲下的校核章。**全直角、工程感、蓝晒夜**。

**运行**：双击 `index.html`（Chrome/Edge 推荐）。离线可用，无外部依赖，~104KB 单文件。

## 信息架构（与 A/B 完全不同）

```
#board（绘图室 grid：图纸 | 图签栏 / 甲板 | 制图台）
├─ #head      顶栏：品牌（C 方框 logo）· 制图/规格书 段控 · 母图面包屑 · 钮组（图签栏/检索/配景/台账/晒印/规程）· 晒·蓝晒 切换
├─ #sheet-area 图纸区（方格纸底纹 + 内框线，左缘 2px 墨线）
│   ├─ #dim-rail   横向尺寸线轨道（64px）：基线 + 菱形刻度节点
│   │   ├─ .dnode  每幕一节点（N01/N02 编号 + 时位缩写 + commit 着色）
│   │   └─ NEXT    虚线待制图占位（轨道尽头的呼吸感）
│   ├─ #sheet-scroll 横向滚动区（叙事从左到右推进！）
│   │   ├─ .detail    节点详图卡：图号头（N01·标题·CHECKED/PENDING）+ 正文 + 修订气泡
│   │   ├─ .change-order  变更单（用户行动，赤锈虚线框；PICK=实线）
│   │   └─ .scene-head   场景标题栏（图纸表格式三格：纪年｜时辰｜地点）
│   └─ #design-host 规格书工坊（内核设计模式）
├─ #side      右侧图签栏（300px）：世界线清册（菱形点）+ 九大台账迷你格
├─ #desk-bar  制图台：多选编队 · 灵感速写 · 输入区 · 提交
└─ #pet       制图精灵（圆规，双腿张合摆动）
```

## 隐喻系统

| 产品概念 | 视觉语言 |
|---|---|
| 世界线（会话） | 图签栏里的一行清册；IF 分叉 = 「接续单」 |
| 一幕（回合） | 尺寸线上的菱形刻度节点 + 一张节点详图卡（从左向右追加） |
| 落账（commit） | 校核章 `stamp-in`（rotate -8°→-3° 盖下，文案「校核已入账 · N 笔」） |
| 待补录 | 铁锈红徽标 + 「待校核」虚章，一键补录转实章 |
| 玩家行动 | 变更单（REV-编号 + 赤锈虚线框，PICK 为实线框） |
| IF 分叉 | 修订气泡悬停 →「另开一线」→ 新接续单，母图面包屑 ⟲ |
| 状态面板 | 「SCHEDULE OF MATERIALS · 状态清单」材料表样式 |
| 快照 | 台账中的「存档图筒」 |
| 内核设计 | 顶栏切「规格书」→ 规格书工坊（契约检查点 + 内核库） |
| 主题 | 描图纸（昼，牛皮纸面 `#E7E4DC`）↔ 蓝晒纸（夜，`#12324E` 经典氰版蓝） |

## 快捷键

Ctrl+K 命令面板 · Ctrl+1 图签栏开合 · Ctrl+P 台账 · Ctrl+G 配景集 · Ctrl+F 检索 · Ctrl+/ 规程 · Enter 提交 / Shift+Enter 换行

## 标志性瞬间

- **横向叙事**：详图卡随回合从左向右铺开，尺寸线轨道同步生长——翻阅故事就是滚动图纸
- **蓝晒切换**：描图纸（米白+墨线）一键切换为蓝晒纸（普鲁士深蓝+晒相白），经典氰版印象
- **全直角**：整站 `border-radius:0 !important`（`--r:0px`），唯一的「圆」是菱形刻度的 45° 旋转
