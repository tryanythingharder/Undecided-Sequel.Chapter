# DESIGN SPEC · C 蓝晒制图台（绘图桌架构 v2）

版式根基：一张**工程图纸**。横向尺寸线是时间轴，节点详图卡从左向右铺开，一切元素遵循制图规范——表格化场景头、材料表状态清单、修订气泡、图签栏、校核章。**全直角**是方向 C 的身份：`*{ border-radius:0 !important }`，唯一的角度语言来自菱形（正方形旋转 45°）。

## 色彩 Token（命名色）

| Token | 描图纸（昼，默认） | 蓝晒纸（夜） | 用途 |
|---|---|---|---|
| `--desk` | `#E7E4DC` | `#0D1B2A` | 图桌底 |
| `--sheet` | `#F6F5F0` | `#12324E` | 图纸面 |
| `--ink` | `#20242E` | `#E4EEF6` | 制图墨/晒相白 |
| `--prussian` | `#1F4E79` | `#7FB4E0` | 普鲁士蓝：主操作/尺寸线/选中 |
| `--cyan` | `#3E7CA6` | `#6FA8CC` | 蓝晒青：注释/修订气泡 |
| `--stamp` | `#C2542F` | `#F49E7C` | 铁锈红：校核章/变更单/待办 |

对比度实测：正文 蓝晒 14.79:1 / 描图 12.21:1（WCAG AAA 级）。

## 字体角色

- **宋体**（`Songti SC/SimSun/STSong` 栈）——图纸注记正文（工程注记的正式感）
- 系统黑体——界面元素
- 等宽（`Cascadia Code/Consolas`）——**占比最高的一套**：图号（N01）、刻度标签、尺寸标注、REV 编号、材料表——制图台以「标注」为空气

## 版式构件（独有）

- **尺寸线轨道**（64px 横条）：群青基线 + 菱形刻度节点（45° 方块）；commit 着色（普鲁士=已校核、锈红=待办）；`NEXT` 虚线占位；节点间隔自带工程双箭头细分线
- **节点详图卡**（`min(420px, 84vw)`）：墨线 1.5px 外框 + 图号头（N01 · 标题 · 状态徽）+ 正文 + 修订气泡 + 校核章
- **场景标题栏**：图纸表格三格（`甲龙历407.03.01｜清晨｜布耶纳村`），1px 分隔——完全去叙事化的工程表头
- **材料表**：状态台账渲染为 `SCHEDULE OF MATERIALS`——上眉标 + 单行框，等宽字体
- **变更单**：用户消息 = 赤锈虚线框单据（PICK 实线），REV-xx 编号
- **校核章**：`stamp-in` keyframe（rotate -8°→-3°、scale 1.4→0.96→1 落章），文案「校核已入账 · N 笔」
- **图签栏**（右 300px）：清册 + 九账迷你格；蓝晒态下整体换 cyanotype token
- **方格纸**：28px 网格（`--grid` 8–10% 透明度）+ 内框线 10px inset——图纸的空气感

## 动效令牌

`--dur-1..4 = 130/200/260/460ms`；`--ease-stamp cubic-bezier(.34,1.4,.42,1)`；`detail-unroll` 详图入场（上移 10px 淡入）；`compass-sway` 圆规 ±4° 摆动 4s。
全程无 glow、无 blur——方向 C 的光影只有「晒」：蓝晒态靠底色反转而非阴影。

## 桌宠

制图精灵（圆规）：SVG 双腿 + 普鲁士蓝铰链 + 锈红笔芯。`compass-sway` 恒定摆动 = 校准中；「收拢」后动画归 none（腿并拢）；👀→✕ 表情切换。

## AI-tell 规避（frontend-design skill 原则映射）

- ✗ 无任何圆角卡片套件（全直角是身份而非缺陷）
- ✗ 无居中渐变英雄、无彩色玻璃光晕——蓝晒靠色相反转，不靠发光
- ✗ mono 字体虽大量使用，但全部是**功能标注**（图号/尺寸/REV），不做装饰性数据标签
- ✓ 标志性瞬间：横向铺开的图纸 + 一键蓝晒显影
- ✓ 表格线语言（1px 分隔）代替卡片阴影；阴影仅抽屉/灯箱两处

## 无障碍

- 正文对比度 12.21–14.79:1；交互全键盘可达；焦点环普鲁士蓝 2px
- `prefers-reduced-motion` + 晒印设置内手动动效开关
- 菱形刻度节点带 `cursor:pointer` 且支持点击跳转详图（键盘 Tab 顺序可达）
