# 六面世界 · 三方向交互原型（v2 全新架构重写）

> 通用故事引擎「六面世界」的桌面交互原型。三个方向各自拥有**完全不同的信息架构与交互范式**——不是换肤，是三种世界观各自长出的界面。
> 均为单文件 HTML（约 100–180KB）：双击任一 `index.html` 即可在浏览器离线运行，无任何外部依赖与网络请求。

## 三种架构，一眼分野

| | A · 墨靖书房 | B · 群青观测站 | C · 蓝晒制图台 |
|---|---|---|---|
| **世界观** | 世界是一部线装书，每次抉择盖一枚朱砂印 | 你是观测者，世界线是星图上的星座，叙事从取景框传来 | 世界是一张图纸，每幕是一处节点详图，抉择是变更单 |
| **导航范式** | 右侧**书脊**：竖排世界线书签舌（writing-mode: vertical-rl），右键管理 | 左侧**星图舱**：SVG 星座图（节点=幕、连线=轨道、IF=赤焰虚线）+ 世界线清册 | 顶部**尺寸线轨道**：横向时间轴，菱形刻度节点，点击跳转详图 |
| **叙事版式** | 竖向卷轴：鱼尾界栏 + 楷体正文 + 右缘朱批（悬停出操作） | 观测窗：取景框四角 + REC 读数 + 宋体观测记录 + 附注可分叉 | 横向图幅：从左到右滚动，每幕一张竖版详图卡，变更单穿插其间 |
| **主色调** | 宣纸昼 `#F2F1EB`（默认亮）/ 靛夜 `#14161D` | 外空夜 `#0B0E1A`（**默认暗**，夜是主场）/ 白昼班 | 描图纸 `#F6F5F0`（默认亮）/ 蓝晒纸 `#12324E` |
| **命名色** | 群青 `#2F4C7E` · 朱砂 `#B8402E` · 苔青 | 群青 `#5B8DEF` · 信标绿 `#4ED6A9` · 琥珀 · 赤焰 | 普鲁士蓝 `#1F4E79` · 蓝晒青 · 铁锈红 `#C2542F` |
| **叙事字体** | 楷体（手稿） | 宋体（观测记录） | 宋体（图纸注记） |
| **圆角语言** | 3px（书角微圆） | 10px（舱体圆润） | **0px（全直角）** |
| **落账仪式** | 朱砂印 `seal-in`（scale 2→0.94→1 旋转落章） | 信标点亮（绿光 + bounce） | 校核章 `stamp-in`（rotate -8°→-3° 盖下） |
| **IF 分叉** | 朱批上「另开一线」→ 新书签舌 | 附注上「另开一线」→ 星图新增赤焰星座 | 修订气泡「另开一线」→ 接续单 |
| **桌宠** | 墨滴「世界之灵」（呼吸、思考、入睡） | 信标卫星 BEACON（轨道环旋转、休眠） | 制图精灵（圆规，摆动校准、收拢） |
| **性格一句话** | 文人的、仪式感的 | 浪漫的、宇宙尺度的 | 冷峻的、工程精确的 |

## 如何运行

```
docs/prototype/
├─ A-墨靖书房/index.html     # 双击打开（Chrome/Edge 推荐）
├─ B-群青观测站/index.html
├─ C-蓝晒制图台/index.html
└─ README.md                 # 本文件
```

每套目录内另有 `README.md`（运行与交互地图）与 `DESIGN-SPEC.md`（设计令牌 / 动效规范 / skill 原则映射）。

## 功能等价矩阵（三套全部具备，实测通过）

**会话与故事流**
- 4 出身笺开卷（保留记忆的转生者 / 洛琪希的学生 / 村中孩子 / 贵族私生子）
- 打字机流式叙事（105 cps）→ 场景行结构化 → 【你需要决定】选项 → 简要状态台账
- 自由输入回合（Enter 发送 / Shift+Enter 换行）+ 多选编队 + 灵感注入（不耗 token）
- 落账状态机：正常落账（86%）→ 静默重试自动补录（8%）→ 待补录挂起一键补录（6%），带回合日志

**世界线管理**
- 新建 / 重命名 / 删除（确认对话框）/ 切换，母线面包屑（⟲ 母线/母图：xxx）
- IF 分叉：从任意幕切出新线，母线完整保留；三套各自有分叉视觉（书签舌 / 赤焰星座 / 接续单角标）

**台账与资产**
- 九大台账（抉择/誓约/事实/见闻/事件/因果/羁绊/线索/名目）实时计数——侧栏或抽屉可视化
- 快照：创建 / 回溯 / 删除，上限 30 份
- 影像库 / 配景集：SVG 种子生成插图（三套各一画风：水墨山居 / 星野轨道 / 工程线稿），灯箱放大

**内核设计**
- 模式切换（正文 ↔ 内核设计/规格书工坊）
- 契约检查点（7 项可勾选，进度条）+ 内核库 5 卡（内置已发布 ×2、自定义草稿 ×2、归档 ×1）可装载

**外观与可达性**
- 双态主题（每套命名不同：宣纸昼/靛夜、夜班/白昼班、描图纸/蓝晒）
- 阅读字体 / 行宽 / 密度切换，localStorage 持久化（file:// 降级内存态，三套 key 隔离）
- 实测正文对比度全部 ≥ 12:1（A 12.88/13.39，B 夜 14.69/昼 12.61，C 蓝晒 14.79/描图 12.21），远超 WCAG AA
- `prefers-reduced-motion` + 手动动效开关；键盘全可达（Ctrl+K 命令面板、Ctrl+P 台账、Ctrl+G 画廊、Ctrl+F 检索、Ctrl+/ 帮助、Esc 逐层关闭）
- 响应式：≤1080 侧舱抽屉化、≤640 移动端布局实测可用

## 引擎语义保真（与真实产品对齐）

- 协议尾形态：`<<<STATE_PATCH>>> … <<<END_PATCH>>>`，解析失败不落账
- 落账字段：scene/facts/entities/events/commitments/threads/knowledge/causal …（九大账各有落位）
- 快照上限 30；回合日志保留 40 条
- 内核元数据：builtin/custom × published/draft/archived，每工作区绑定一个内核

## 模拟边界（原型说明）

- 「模型输出」为内置叙事模板池（三套共用同一池保证评审公平）
- 设置中的密钥配置为只读展示；导出/保存类动作为 toast 模拟
- 本目录不改动项目任何其他代码（`renderer/`、`renderer-proto/`、`engine/` 均未触碰）
