# A · 墨靖书房（线装书架构）

> 世界是一部线装书：世界线是右侧书脊上的竖排书签舌，每一幕是卷中鱼尾界栏分隔的一节，你的批注是右缘朱批，每次落账盖一枚朱砂印。

**运行**：双击 `index.html`（Chrome/Edge 推荐）。离线可用，无外部依赖，~180KB 单文件。

## 信息架构（与 B/C 完全不同）

```
.room（书房）
├─ .spine    右侧 64px 书脊：竖排世界线书签舌（vertical-rl）
│   ├─ .wstab     每条世界线一枚书签舌，右键=重命名/删除，钉眼=装订孔
│   ├─ .spine-new ＋ 新世界线（竖排）
│   └─ .brand-seal 「六」字朱印（旋转 -4°，点击回正文）
├─ .leaf     书页本体
│   ├─ .leaf-head  题签页眉：正文/内核设计 双题签 + 印钮（画/检/问/装）+ 昼夜切换
│   ├─ .marginal-tip  眉批横幅（待补录提醒出现在这里）
│   ├─ .scroll-col  纵向卷轴（叙事区，宣纸纸纹）
│   │   ├─ .frontispiece  扉页：4 身世笺（o-zi 汉字 生/师/隐/贵）
│   │   ├─ .beat  一幕：鱼尾界栏场景行 + 楷体正文 + 朱批 + 便笺选项 + 落印
│   │   └─ .zhu-note  你的批注（右对齐朱批，悬停出 抄录/另开一线/配图）
│   └─ .inkstone   砚台输入区（墨点圆钮 = 发送）
├─ .booklet  右滑册页：画廊/主题/帮助/检查册（九大账+拓片+日志）
└─ #pet-ink  墨滴桌宠「世界之灵」
```

## 隐喻系统

| 产品概念 | 视觉语言 |
|---|---|
| 世界线（会话） | 书脊上的竖排书签舌；IF 分歧线带标记，母线面包屑 ⟲ 显示在页眉 |
| 一幕（回合） | 鱼尾界栏（宋版书版式）分隔场景行 + 两字缩进楷体正文 |
| 落账（commit） | 朱砂印 `seal-in`（scale 2→0.94→1 旋转落章，文案「印已入账 · N 笔」） |
| 待补录 | 卷首眉批横幅 + 空印虚框，一键补录后转实印 |
| 玩家行动 | 你的批注以朱批样式右缘排布（「批」字竖排签头） |
| IF 分叉 | 朱批上悬停 →「另开一线」→ 书脊多一枚新舌，母线完整保留 |
| 快照 | 检查册中的「拓片」——碑帖拓片隐喻 |
| 内核设计 | 页眉切「内核设计」题签，进入设计册（契约检查点+内核库） |

## 快捷键

Ctrl+K 命令面板 · Ctrl+Alt+I 检查册 · Ctrl+F 检索 · Ctrl+G 画廊 · Esc 逐层关闭 · Enter 发送 / Shift+Enter 换行

## 启动序列（标志性一瞬）

卷轴自上而下展开（`scroll-unfurl` clip-path）→ 一滴墨自空中落下晕开（`drop-fall`）→ 墨中浮出「六」字朱印（`seal-stamp`）→ 扫描线定版（`scan-sweep`）。可跳过；`prefers-reduced-motion` 下直接呈现终态。
