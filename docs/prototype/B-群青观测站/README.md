# B · 群青观测站（观测舱架构）

> 你是观测者。每条世界线是左舷星图上的一座星座（节点=幕、连线=轨道），叙事信号从中央取景框传来，落账是轨道上亮起的信标。**夜是主场**——默认外空深蓝，白昼只是观测者小憩的班次。

**运行**：双击 `index.html`（Chrome/Edge 推荐）。离线可用，无外部依赖，~116KB 单文件。

## 信息架构（与 A/C 完全不同）

```
#bridge（舱体 grid：星图 | 主区 / 甲板 | 传输台）
├─ #deck     顶栏甲板：品牌（行星+卫星环 logo）· 观测/内核设计 段控 · 母线面包屑 · 圆钮组（星图/检索/影像/台账/主题/规程）· 夜/昼班
├─ #scope    左舷星图舱（264px，可收合）
│   ├─ #starmap-svg  SVG 星座图：每条世界线一座星座
│   │   ├─ 实线轨道 = 普通线；赤焰虚线 = IF 分支
│   │   ├─ 节点 = 幕（当前线的节点呼吸放大 animate）
│   │   └─ 46 颗背景参考星
│   └─ #starmap-list  世界线清册（右键=重命名/删除）
├─ #main     观测窗
│   ├─ #viewport  取景框：四角括号 + REC 红点读数（线名/R数）
│   └─ #scroll-host  宋体观测记录流（场景坐标点行 + 附注 OBS）
├─ #console-bar  传输台：UPLINK 活性波形（canvas，busy 时变绿）· HUD 芯片列（台账/回合/待同步/快照/IF）· 输入区 + 多选编队 + 灵感脉冲
├─ .drawer   右滑抽屉：台账（九账格+锚点+日志）/ 影像库 / 主题 / 规程 / 检索
└─ #pet      信标卫星 BEACON（轨道环旋转）
#starfield   全屏 canvas 恒星场（昼夜密度不同）
```

## 隐喻系统

| 产品概念 | 视觉语言 |
|---|---|
| 世界线（会话） | 星图上的一座星座；IF 分叉线 = 赤焰色虚线星座 |
| 一幕（回合） | 轨道节点 + 坐标点场景行（等宽字号 11px，观测记录体） |
| 落账（commit） | 信标点亮：绿光 + bounce（`seal-in` 变体，文案「信标已亮 · N 笔」） |
| 待补录 | 琥珀警示：甲板徽标 + HUD「待同步」芯片 + 幕上虚线信标，一键补录 |
| 玩家行动 | UPLINK/PICK 上行气泡（PICK 用赤焰描边） |
| IF 分叉 | 附注（OBS）悬停 →「另开一线」→ 星图新增赤焰星座，母线面包屑 ⟲ |
| 快照 | 台账中的「星图锚点」 |
| 桌宠 | 信标卫星：轨道环（dashed）旋转 + 绿色子卫星；休眠后点击唤醒 |

## 快捷键

Ctrl+K 命令面板 · Ctrl+1 星图开合 · Ctrl+P 台账 · Ctrl+G 影像库 · Ctrl+F 检索 · Ctrl+/ 规程 · Enter 发送 / Shift+Enter 换行

## 标志性瞬间

- **全屏恒星场**：canvas 逐星 twinkle，昼夜两套密度/亮度；busy 时传输台波形变绿（上行中）
- **星座呼吸**：当前世界线的每个节点 `animate` r 3.4→4.6 循环放大
- **取景框 REC**：右上角红色录制点闪烁 + 实时线名/回合读数——观测感的核心构件
