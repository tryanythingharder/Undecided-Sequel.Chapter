# DESIGN SPEC · B 群青观测站（观测舱架构 v2）

版式根基：一座**观测舱**。左舷星图导航、中央取景框叙事、甲板 HUD、底部传输台。夜里工作，昼间小憩——夜态为默认主场，昼态是从属班次（与 A 恰好互为镜像）。

对比度实测：正文 夜 14.69:1 / 昼 12.61:1（WCAG AAA 级）。

## 字体角色

- **宋体**（`Songti SC/SimSun/STSong` 栈）——观测记录正文：星历志气质（与 A 的楷体明确区分）
- 系统黑体——界面元素
- 等宽（`Cascadia Code/Consolas`）——坐标/时间码/台账数据

## 版式构件（独有）

- **左舷星图**（264px）：SVG viewBox 100×100；每线一座星座（种子化定位节点）；当前线节点 SVG `<animate>` 呼吸；IF=赤焰虚线；46 颗背景参考星
- **取景框**：四角 22px 括号（群青 2px 边）+ REC 闪烁红点 + 线名/回合等宽读数
- **上行气泡**：用户消息 = UPLINK/PICK 气泡，PICK 赤焰描边
- **附注 OBS**：竖排「OBS」签头 + 群青左边线，悬停出 抄录/另开一线/配影像
- **频段选项**：`.choices` 盒（"频段选项 · SELECT CHANNEL" 标）+ 键字母导频
- **传输台**：UPLINK canvas 波形（idle 群青低幅 / busy 信标绿高幅）+ HUD 芯片列
- **信标落账**：`.beat-seal` 圆环信标 + `seal-in` bounce（文案「信标已亮 · N 笔」）
- **恒星场**：全屏 canvas，逐星 twinkle（`Math.sin(t·sp+tw)` 相位），昼班密度减半

## 动效令牌

`--dur-1..4 = 130/200/260/460ms`；`--ease-bounce cubic-bezier(.34,1.56,.42,1)`（信标过冲）；`beat-dock` 幕入场 260ms 上移淡入。
全局克制：无大位移；星体 twinkle 与星座呼吸是仅有的两处循环动画（busy 波形除外）。

## 桌宠

信标卫星 BEACON：群青渐变星体 + 虚线轨道环（`pet-spin` 9s 旋转）+ 绿色子卫星（环上小点）+ 底部名称牌。问答走 PET_RULES 规则库（观测语言改写）；休眠后点击唤醒。

## AI-tell 规避（frontend-design skill 原则映射）

- ✗ 避开「near-black + acid-green」组合：深空底是**带蓝的** `#0B0E1A`，绿是**带青的** `#4ED6A9`，仅作点睛不作正文
- ✗ 无 ALL-CAPS 眉标堆叠（英文只出现在 mono 读数/缩写，中文主导）
- ✗ 无居中英雄式渐变横幅；色带只出现在取景框雾效（8–9% 透明度）
- ✓ 标志性瞬间：星座随回合生长 + 星域呼吸，页面其余保持静默
- ✓ 每帧 canvas 动画 <2ms（90 星点），60fps 无压力

## 无障碍

- 正文对比度 夜 14.69 / 昼 12.61:1；交互全键盘可达；焦点环群青 2px
- `prefers-reduced-motion` + 手动动效开关（关闭后星场停绘，canvas 跳过 rAF 绘制）
- 抽屉/命令面板 Esc 逐层关闭；toast aria-live
