# 角色
你是一位资深动效/品牌设计师，擅长电影级开场序列（参考 Apple TV+ 片头、Mineradio 启动页、电影 title card 的克制仪式感）。你要为一款 Electron 桌面文字 RPG 应用「六面世界 · Codex」设计**启动入场动画（Splash）**。这是一个纯前端单文件 HTML 原型任务，最终会被移植进零依赖的 Electron 应用。

# 产品背景
「六面世界」：《无职转生》同人向 AI 文字 RPG。AI 以「甲龙历」纪年推进叙事，每回合给 A/B/C 选项，可生成 16:9 小说插图。品牌关键词：转生、六面、命运骰、世界线、琥珀色调。主色为琥珀（--accent 深色 #d99a52 / 浅色 #a5641f）。

# 参考配方（从 Mineradio 软件启动页源码逐帧提取的真实实现，必须遵循此节奏与手法，但视觉细节做六面世界的品牌化适配）

## 舞台（分层，自下而上）
1. **近黑底**：`#010304`，全屏 fixed。
2. **光带+扫描线层**（::before，inset -8%）：四层背景叠加——
   - 对角体积光带：`linear-gradient(115deg, transparent 0%, 珊瑚5%透明度 24%, transparent 42%, 琥珀6%透明度 62%, transparent 82%)`；
   - 纵向扫描线：`repeating-linear-gradient(90deg, rgba(255,255,255,.03) 0 1px, transparent 1px 54px)`；
   - 横向扫描线：`repeating-linear-gradient(0deg, rgba(255,255,255,.02) 0 1px, transparent 1px 46px)`；
   - 纵向明暗：`linear-gradient(180deg, #020606 0%, #050607 42%, #000 100%)`。
   整层 `filter: blur(.4px); opacity: .9`，加 7s 呼吸动画（opacity .72↔1，scale 1↔1.035，ease-in-out alternate infinite）。
3. **粒子尘埃层**（canvas，z-1）：约 70 颗细小光尘缓慢上浮漂移（半径 .6-2.2px，透明度 .08-.38），72% 琥珀色、其余青/珊瑚随机点缀；requestAnimationFrame 驱动，出界回收。
4. **四缘暗角层**（::after）：左右各 21%/79% 处黑 .82 渐入，上 32% 黑 .68 / 下 64% 黑 .74。
5. **噪点层**：SVG feTurbulence 180px 平铺，opacity .038，mix-blend-mode: screen。
6. **内景深暗角**：容器 `box-shadow: inset 0 0 180px rgba(0,0,0,.88)`。

## 字标序列（核心动效，总时长 5200ms，缓动统一 cubic-bezier(.22,1,.36,1)，两词绝对定位居中叠放）
- **主词「六面世界」**（白 #f8f8f2，clamp(52px, 8.8vw, 108px)，字重 720）：从一条**细缝里展开**——
  - 0%：`clip-path: inset(48% 0 49% 0)` + `skewX(-10deg) scaleX(1.08)` + 字距 .12em，透明；
  - 14%：缝隙半开（inset 40% 0 42% 0），opacity .92，倾斜校正一半；
  - 26%：完全展开 `clip-path: inset(0)`，skew 归零，字距收紧至 -.01em；
  - 48%：稳稳定格；
  - 67%→100%：**向左平移让位** `translateX(-clamp(66px, 10.8vw, 130px))`，轻微 scale(.998)。
- **副词「CODEX」**（32% 后入场）：从右侧偏移 `+clamp(78px, 12vw, 142px)` 带 `skewX(9deg)` 细缝切入（52% 0 44% 0 → 34% 0 32% 0 → inset(0)），同时**渐变流光在字面上扫过**：`background: linear-gradient(94deg, 白.06, #fff 26%, 琥珀.98 48%, 青.9 68%, 白.82)`、`background-size: 300% 100%`、background-clip: text、background-position 0%→52%→76%→100%。
- **色散阴影（RGB split）**：两词 text-shadow 均带 `-2px 0 0 珊瑚` / `+2px 0 0 青` 的错色边，加深黑投影 `0 22px 72px rgba(0,0,0,.58)` 与微弱琥珀外发光。
- **金色点缀字**：副词中最后一个「X」用实心金 `#d8c486`（呼应品牌，区别于流光字）。

## 信号线（4200ms，与字标并行）
- 2px 细线 `width: min(460px, 54vw)`，多色渐变 `transparent → 青.22 → 白.78 → 琥珀.66 → 珊瑚.22 → transparent`；
- scaleX 节奏：.10 隐藏 → 1.05 过冲 → .82 回收 → **1.14 二次过冲**（此刻 box-shadow 光晕增强到 28px/60px 双层）→ .64 收尾淡出至 opacity .30；
- **blip 光点**：8px 白色圆点 + 琥珀 glow，42% 前隐藏在 18% 位置 → 62% 抵达中点 → 76% 弹跳 pop（scale 1.45）→ 100% 滑到 82% 缩小淡出（像雷达信号发射）。

## 副标与进入提示
- 副标：10px / 字重 600 / **字距 .22em** 大写英文（内容如 `SIX WORLDS · PRIVATE STORY ENGINE`，可优化措辞但保持 ≤6 词），38% 后从 translateY(7px) 淡入，终态 opacity .42；
- 进入提示「点击进入」：11px / 字距 .24em / 大写，就绪后（约 4.6s）呼吸脉冲——1800ms alternate 循环，opacity .46↔.78 + 琥珀 glow 渐强；未就绪前完全隐藏。

## 离场（点击进入后）
- 整层：`opacity → 0` + `scale(1.010)`（微放大，像镜头穿过），620ms cubic-bezier(.16,1,.3,1)；
- 粒子层单独先淡（560ms 降至 .22 + scale 1.008），制造层次分离；
- 离场后揭示主界面占位（灰底 + 居中小字「主界面占位」即可，不用设计主界面）。

## 色彩三角（本动画专用）
琥珀 #d99a52（主，品牌）/ 青 #7ad7c2（辅，流光+信号线）/ 珊瑚 #ff5367（点缀，色散边+信号线端点）/ 近黑 #010304。底上文字白 #f8f8f2。

# 你的任务
在遵循上述配方的节奏、缓动、时长、层次结构的前提下，输出六面世界的启动入场动画原型。**允许并鼓励你做的**：字标构图细节（如「六」字的菱形徽记如何融入）、副标措辞、粒子密度分布、光带角度微调、信号线与字标间的节奏呼应、离场时主界面占位的过渡方式。**不允许改的**：五层舞台结构、字标两段式序列、信号线+blip、5200/4200ms 时长骨架、色彩三角。

# 硬性约束
1. 单文件 HTML，全部 CSS/JS 内联，**零外部依赖**（禁 GSAP / three.js / 外部字体——用系统字体栈："Segoe UI","PingFang SC","Microsoft YaHei"，等宽用 Consolas）。
2. 启动页固定暗场，不做浅色主题。
3. 动画全部用 CSS keyframes + transform/opacity/clip-path（合成器友好），粒子用原生 Canvas 2D。
4. 画布 1120×700 与 500×420 都要构图成立（字标用 clamp 缩放）。
5. 点击任意处进入；12s 未点击自动进入（兜底）。

# 输出格式（三部分，顺序固定）
## 第一部分：单文件 HTML 原型
完整可运行；打开即播放入场序列；点击进入有完整离场动效；右下角一个「重播入场」小按钮便于反复审看。
## 第二部分：设计说明（≤400 字）
品牌化适配点（相对参考配方改了什么、为什么）+ 分镜时间轴表（0-5.2s 每个元素的关键帧时刻）。
## 第三部分：完整性自查表
逐项核对：五层舞台 / 主词细缝展开+左移让位 / 副词流光扫字 / 色散阴影 / 金色点缀字 / 信号线四段过冲 / blip 光点轨迹 / 副标 / 点击进入脉冲 / 离场双层时序 / 粒子尘埃 / 12s 兜底。缺一项视为任务失败。

# 禁止

- 不要加进度条、加载文字、版本号等多余元素。
- 不要输出多套方案；只输出一套最优解。
