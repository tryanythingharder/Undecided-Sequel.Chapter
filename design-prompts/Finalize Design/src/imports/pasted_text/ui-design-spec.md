# 角色

你是一位资深桌面应用 UI 设计师，擅长**沉浸式、电影感**的界面语言（参考 Mineradio 的暗场舞台氛围 + Apple 灵动岛的弹性 morph 动效 + Linear 的克制排版）。此前你为本应用完成过两轮设计：①消息流+选项区+灵动岛（电影暗场舞台）②启动入场动画。本轮继续同一套设计语言，把**其余所有次级界面**统一到这个体系里：初始化向导、免责声明、设置窗口、确认框、帮助弹窗、主题弹层、画廊与大图查看。

# 产品概述

应用名为「六面世界」：《无职转生》同人向 AI 文字 RPG。AI 以「甲龙历」纪年推进叙事，每回合输出 A/B/C 选项，可生成 16:9 小说插图。Electron 桌面应用，中文界面。注意：界面上只出现「六面世界」品牌名，任何其他英文代号不得出现在 UI 文案中。

## B. 氛围 token（已落地）

--glass 半透明底（深 rgba(28,28,32,.58) / 浅 rgba(255,255,255,.66)）+ backdrop-blur(16-28px) saturate(1.3-1.5)；1px 玻璃描边 + 内高光 inset 0 1px 0（深 rgba(255,255,255,.10)）；--stage 暗场画布（深 #000000 / 浅 #ffffff，顶部中央琥珀环境光晕 + 2-5% 胶片噪点）；--ease-spring cubic-bezier(.32,1.35,.35,1)。琥珀 accent 在纯白/纯黑世界里是唯一的彩色信号——克制使用。

## C. 五个关键手法（继承，不许丢）

1. **玻璃面板**：所有浮层容器 = 玻璃底 + blur + 内高光 + 大圆角（16-20px）+ 三档阴影中最重一档。
2. **琥珀只做强调**：选中态、焦点环、主按钮、进度节点、危险以外的关键动作；绝不大面积铺色。
3. **弹性动效**：弹入 spring、勾选 ✓ scale 弹跳、hover 上浮 2-3px + 光环。
4. **mono 微标签**：字段标签、步骤计数、快捷键 kbd、统计数字一律等宽小字（11-12px，字距 .05em）。
5. **排版层级**：h3 分组标题 12px 大写字距弱化色；正文 14px；控件行高统一 32-36px。

## D. 语境分级（本轮核心思想：同为玻璃语言，但按场景分三种「角色」）

- **仪式级（向导、免责声明）**：第一次见面，允许最丰富的舞台感——顶部细环境光晕渗入、入场 scale(.96)+blur 过渡 spring 展开、步骤节点像进度光点。
- **工具级（设置窗口、画廊、帮助）**：高频工作台——信息密度优先、装饰收敛到分组线与 hover 反馈、滚动区域干净（无装饰性背景）。
- **瞬时级（确认框、toast 类轻交互、主题 popover、lightbox）**：来去安静——短 spring（.35s 内）、遮罩更淡、体量最小。

# 结构清单（元素一一保留，id/文案冻结，一个不丢）

## E. 初始化向导（模态 640px，三步固定高度不跳变）

1. 头部：渐变琥珀「六」字徽记 + 「欢迎使用六面世界」+ 副标「三步完成初始配置，所有选项之后都能在设置中调整」。
2. 圆点步骤条：3 节点（当前=琥珀实心+光环 / 已过=✓ / 未到=空心）+ 连接线随进度填充；步骤名：外观 · 对话模型 · 插图模型。
3. 第 1 步「选择外观」：三张主题卡（纯白/纯黑/跟随系统，各含 CSS 迷你界面预览小窗侧栏+正文，选中 ✓ 角标弹出）+ **配色方案行**（7 枚预设圆片双色调渐变 + 名称：经典/羊皮纸/林间/紫晶/海渊/蔷薇/高对比，点击即时预览全局换肤）+ 底部提示「随时可以在右上角主题按钮或设置中更改」。
4. 第 2 步「配置对话模型」：7 张提供商预设卡（DeepSeek/OpenAI/Moonshot Kimi/智谱 GLM/通义 Qwen/硅基流动/自定义＋，首字头像）+ API Key 密码框 + 模型下拉/手填框 + 「拉取模型」按钮 + 结果状态行（成功绿/失败红）。
5. 第 3 步「配置插图模型」：「暂不启用」预设卡 → 选中时整步显示虚线空状态卡（图片图标+说明）；启用任一提供商后切换为 API Key + 模型拉取表单。
6. 底部：左「第 X / 3 步」（mono）· 右「跳过/上一步」+ 主按钮「下一步 →」/「完成」，箭头 hover 位移。
7. 动效：切步方向感知滑动（前进从右入/后退从左入）；**三步画布高度完全一致**（垂直居中补偿）。

## F. 免责声明（向导完成后接续，640px 模态）

标题「配置完成前 · 请先阅读免责声明」+ 可滚动正文（5 条编号条款，编号用 mono 琥珀）+ 底部勾选行「我已阅读并同意…」+ 唯一主按钮「同意并继续」（未勾选禁用置灰）。

## G. 设置窗口（独立 560×700 小窗）

1. 自绘标题栏：拖动区 + 「重置」幽灵钮 + 最小化/最大化/关闭三钮。
2. 四个 tab：文本模型 / 插图模型 / 外观 · 内核 / 高级（激活 tab 琥珀下划线或胶囊）。
3. 表单语言全量精修：label（12px dim）/ input-select-password（36px 行高、focus 琥珀描边+光环）/ checkbox row / 细分隔 hr / `<details>` 高级参数折叠条（展开平滑 height 过渡）。
4. 文本模型页重点组件：模型组合框（输入框 + 获取模型/测试两枚幽灵迷你钮 + 下拉清单含筛选框与「没有匹配的模型」空态）+ 测试结果行（✓ 连接成功…绿色 / ✗ 红色）+ 模型多选清单卡（勾选要在对话栏出现的模型）+ 手动添加行。
5. 插图页：自动插图总开关 + 接口组 + 风格预设（7 项）/ 画面尺寸（含 16:9 默认标注）/ 清晰度 / 高级折叠组（反向提示词、seed 锁定、生成张数）。
6. 外观页：调色板 select + 明暗模式 + 字体/圆角/密度/布局/方向 + 置顶开关 + 字号/内容宽度 + 内核路径选择。
7. 高级页：上下文条数/本地保留条数/插图触发字数/提示词前缀 + 数据管理三钮（清空全部世界线=危险红色幽灵钮 / 导出配置 / 导入配置）。
8. 底部常驻操作条：左状态文字位（保存成功灰绿一闪）+ 右「取消」「保存设置」主按钮。

## H. 通用确认框（复用组件，四种实例都要展示）

模态遮罩 + 玻璃小板（≤480px）：①删除世界线（正文一句话 + 取消 + 危险实心「删除」）②重命名（单行输入预填现名 + Enter 提交）③新建工作区（输入名字 + 创建）④IF 分歧命名（说明文案 + 输入 + 创建分歧线）。风格：瞬时级、短 spring 入场、Esc=取消、回车=确认。

## I. 帮助弹窗（模态，双 tab）

头部「帮助」+ 关闭钮 → tab「怎么玩 / 快捷键」。怎么玩 = 4 组图文条目（第一步开始转生 / 第二步推进故事 / 第三步分歧与回溯 / 更多）；快捷键 = 3 组 kbd 表格（对话 / 导航 / 大图查看），kbd 用 mono 圆角小块。

## J. 主题弹层（标题栏主题按钮下的 popover）

明暗三段选择（跟随系统/深色/浅色，激活琥珀）+ 分隔线 + 7 枚调色板 swatch（双色斜切圆片 + 名称，激活带琥珀描边）；点击即生效并带轻微 pulse 反馈。

## K. 画廊 + 大图查看

1. 画廊：右滑出半屏面板（或全屏浮层，二选一并说明理由）——头部（「画廊」+ 世界线数量 mono 小字 + 关闭）/ 工具条（世界线下拉 + 保存全部插图 + 导出为故事存档）/ 卡片网格（16:9 缩略图 + 叙事摘要两行截断 + meta 行（回合号 mono）+ 悬停浮现四个动作钮）/ 空状态。
2. 大图 lightbox：近黑遮罩（深 .82/浅 .72）居中大图 + 底部极简条（文件名 mono + 关闭 ×/Esc 提示），点击遮罩关闭。

# 硬性约束

1. 单文件 HTML，CSS 全内联，**零外部依赖**（无外部字体/图标库/框架；图标 16px/1.5px stroke 内联 SVG 或汉字按钮）。
2. **元素不增不删不改文案**：以上 E-K 的 id 语义、标题、按钮字面全部冻结；层级与排版可重新设计。新增视觉元素（如图标、分隔符）需在说明里单独列出提案。
3. 只用 A+B token；确需新 token 单独提案，附深浅双值。
4. 右上角提供 data-theme 切换按钮（深/浅双主题都必须完整成立）；再提供演示导航可在 E-K 七个界面间快速切换预览。
5. 所有模态在小窗（500×420 视口）下不破版（向导 640px 允许收缩为 min(640px, 94vw)，三卡换单列纵排可用）。
6. 动效遵循语境分级 D 与 --ease-spring；`prefers-reduced-motion` 下全部动效退化为直接切换。
