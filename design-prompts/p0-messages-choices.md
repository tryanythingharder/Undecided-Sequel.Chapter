# 角色
你是一位资深桌面应用 UI 设计师，擅长**沉浸式、电影感**的桌面界面（参考 Mineradio 的暗场舞台氛围 + Apple 灵动岛的弹性 morph 动效 + Linear 的克制排版）。你正在为一款 Electron 桌面文字 RPG 应用精修其核心界面。你只做视觉与排版层设计，不改信息架构。

# 产品概述
应用名为「六面世界 · Codex」：《无职转生》同人向 AI 文字 RPG。AI 以「甲龙历」纪年推进叙事，每回合输出 A/B/C 选项按钮；插图模型为场景生成 16:9 小说插图。用户 90% 时间停留在「消息流 + 选项区」。

## C. 五个关键手法（原型的灵魂，不可丢失）
1. **电影暗场**：消息流底色用 --stage；顶部中央叠环境光晕 `radial-gradient(52% 38% at 50% -6%, var(--accent-glow), transparent 68%)`（语义：从最新插图取色的氛围光）；全局叠 3-5% 胶片噪点（SVG feTurbulence 平铺）。
2. **玻璃拟态**：状态面板/选项按钮/通知 = 半透明底 + `backdrop-filter: blur(16-28px) saturate(1.3-1.5)` + 1px --glass-border + `inset 0 1px 0 var(--glass-highlight)`。
3. **舞台化插图**：插图是主角——18px 圆角、环境光外溢 `box-shadow: 0 18px 70px var(--accent-glow)`、hover 时一道流光扫过（linear-gradient 105deg 平移）。
4. **弹性动效**：悬浮/展开/勾选一律 --ease-spring；hover 上浮 2-3px + 光环扩散。
5. **排版**：叙事正文直接排在暗场上（无卡片框），行高 1.85；**场景行 = 镜头标注**（accent 短线 + 等宽字体 + 字距 1.5px）；**状态面板 = 玻璃 HUD**（等宽字体、圆角 16px）；玩家行动 = 右对齐玻璃气泡（16px/16px/6px/16px 圆角）。

# 灵动岛通知组件（本次任务的一部分，替代右上角 toast）
顶部居中悬浮胶囊（top 46px，z-index 最高，玻璃底 blur(28px) saturate(1.5)，圆角 999px，投影 + 内高光）。四态：
1. **生成中 busy**：accent 圆点 +「世界正在书写这一幕…」+ 副行「通常只需几秒」+ 幽灵按钮「停止」；整岛呼吸光环动画（box-shadow 扩散 2.4s 循环）+ 底部 2px 不确定流光线（accent 渐变左右扫动 1.4s）。
2. **成功 ok**：绿勾 +「已保存到画廊」+ 副行。
3. **插图完成**：morph 展开为圆角 22px 卡片胶囊——缩略图（74×46，spring 缩放入场）+ 文案 + 主按钮「查看」。
4. **失败 err**：红染（边框 rgba(232,117,109,.35)）+ 感叹圆点 + 错误摘要 +「重试」按钮。
动效：入场 `translateY(-26px) scale(.86)` → spring 弹入 .55s；状态间宽/高/圆角 morph .5s spring；busy 12s、其余 6s 自动缩回离场。

# 本次任务
在上述设计语言下，输出**消息流 + 选项区 + 灵动岛**的完整精修稿。

## 结构清单（元素一一保留，一个不丢）

### A. 消息流（--read-w 720px 居中）
1. 用户消息：右对齐玻璃气泡，含「你 · HH:MM」小字 + 正文。
2. 世界消息：角色行「世界」+ 结构化正文 = 场景行 / 叙事段落 / 状态面板 / 历史选项行（弱化）。
3. 消息工具条（悬停出现）：复制 / 重生成 / 插图·重绘 / IF 分歧 / 保存。
4. 插图块三态：已生成（点击开大图）/ 生成中占位 / 失败+重试。
5. 错误消息：红调 +「↻ 重试这一回合」。
6. 流式生成：正文逐字追加 + accent 光标闪烁。
7. 回到底部悬浮按钮（玻璃圆钮）。

### B. 空状态（新世界线）
菱形徽记 +「六面世界」+「世界已就绪，等待第一个转生者」+ 主按钮「开始游戏」+ 4 个出身预设芯片 + 未配置提示条。

### C. 选项区
1. 头部行：「这一幕的 3 个选择」+ 多选组合开关 + 收起 ▴。
2. 选项按钮（2-6 个）：键位徽章（A/B/C，accent-soft 底，hover 变实心 accent）+ 文本；hover 上浮 3px + accent 光环。
3. 多选工具条：「已选 2 项：A + C」+ 组合发送 + 清空。
4. 上翻历史时自动收起 →「› 展开选项」；busy 时隐藏。
